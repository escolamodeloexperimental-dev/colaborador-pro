# Colaborador Pro

O **Colaborador Pro** é um aplicativo web responsivo desenvolvido para gestão de escalas, controle de turnos, registro de ponto e diário de bordo para acompanhamento de colaboradoras e cuidadoras.

---

## 🎯 Objetivos do Aplicativo

- **Gestão de Escalas:** Organização visual de turnos e folgas.
- **Registro de Ponto:** Marcação simplificada de entrada, saída e horas extras.
- **Diário de Bordo:** Registro diário de rotinas, medicações e ocorrências.
- **Multiplataforma:** Interface otimizada para acesso em smartphones, tablets e computadores.

---

## 🛠️ Arquitetura Técnica

- **Front-end:** Interface Web Responsiva (HTML5 / CSS3 / JavaScript)
- **Hospedagem:** GitHub Pages
- **Banco de Dados / Backend:** Integração via APIs (Google Sheets / Google Apps Script)
